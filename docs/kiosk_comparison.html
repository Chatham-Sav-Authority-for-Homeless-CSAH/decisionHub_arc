Kiosk Software Comparison

Compass Project — evaluated against ARC project requirements

What ARC is actually building here — and what it isn't ARC does not build any device-monitoring, lockdown, or MDM software. That layer is always a bought product, never something ARC engineers. It comes from one of two places: bundled with the hardware (MetroClick's own SaaS platform is the example on this page), where CSAH pays the kiosk vendor and it's their product — or a separately licensed third-party MDM (SiteKiosk, Scalefusion, KioWare), where CSAH pays that company and "ARC installs" just means configuring the subscription (pointing it at the kiosk's URL, setting lockdown rules), the same kind of setup work you'd do for any SaaS tool, not software development. Either way, the app itself doesn't know or care which one is running underneath it — it's just a website, and the MDM layer's whole job is to lock a browser to that website's URL. Zero code dependency, zero build effort on ARC's side, regardless of which option CSAH ends up paying for. This page is a procurement/cost comparison, not an engineering decision.
How these platforms work All four options lock a device to a URL — the kiosk and the partner app read from the same backend automatically since both are built on a shared API (see ADR-004). Single data source and on-demand content updates are solved at the architecture layer, not by the kiosk software. The differentiators are: how well each manages a remote fleet, how much accessibility tooling is built in for public-facing use, and whether the platform is hardware-agnostic.
Push and SMS notifications Kiosk-triggered notifications (e.g. a user requests a caseworker) are handled by the web app running on the kiosk — not by the kiosk software itself. All four platforms are equivalent here. This is an app architecture decision, not a kiosk software decision.

Verdict
Summary Solid, mature lockdown platform with the strongest accessibility story via JAWS compatibility — but JAWS is a separate license with significant per-unit cost. Weakest on API-driven data sharing. One-time license is appealing for a grant budget but add KioCloud for remote management and the cost picture changes. No device minimum is an advantage at small scale. Best overall fit for this project — and now confirmed as a live option for the MetroClick hardware pick. Purpose-built for public-facing web kiosks — not MDM retrofitted. Built-in CMS and strong API align directly with the single-data-source requirement. Touch-first design suits the unhoused user population. Nonprofit pricing at $120/device/yr is the most favorable of the third-party options, and roughly a sixth of MetroClick's own bundled platform per device. 30-day trial de-risks selection before any procurement commitment. No device minimum. The main remaining step is getting MetroClick's hardware-only configuration formally re-quoted so this comparison is apples-to-apples. Strongest hardware flexibility and best-in-class remote fleet management — the right call if hardware selection ever changes. Renowned for deep kiosk lockdown capabilities. MDM-first means accessibility responsibilities shift entirely to the app layer. Best value per device with no device minimum penalty and NGO pricing available on request. Now confirmed as a live option for MetroClick hardware, same as SiteKiosk. The only column grounded in an actual signed quote — everything else here is still a rate card. Best-documented accessibility and nonprofit terms of any option, and zero extra procurement since it ships with the hardware. The tradeoffs are real: $702/yr/unit net is 6–30× SiteKiosk or Scalefusion per device, and it only runs on MetroClick's own hardware — no fallback if that vendor relationship changes later. Now that MetroClick has confirmed hardware-only is available, this is a genuine choice rather than the default: pay the premium for a pre-integrated, well-documented platform, or take the hardware-only path and license SiteKiosk or Scalefusion separately for a fraction of the cost. Worth getting the hardware-only price formally quoted before deciding — "confirmed available" isn't "confirmed price."

Scores reflect fit to Compass Project requirements only — not general-purpose rankings. Pricing for KioWare, SiteKiosk, and Scalefusion is approximate as of 2026 and unverified against current vendor rate cards — negotiate nonprofit/volume rates before committing. MetroClick's bundled-platform pricing is the exception: confirmed via a formal quote received Jul 23, 2026 (see Kiosk Hardware Comparison doc for full detail). Esper was dropped from this comparison — 25-device minimum and beta Windows support made it a clear no-go independent of the hardware decision.
