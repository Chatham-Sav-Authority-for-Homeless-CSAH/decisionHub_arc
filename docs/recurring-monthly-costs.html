Recurring Annual Costs

Compass Project — Phase 1 handoff item · Ongoing operating costs after launch, shown annually

What's assumed here
  • All figures are annual.
  • Two categories scale directly with kiosk count: Kiosk Software License (HW Monitoring) & Cellular Connectivity.
  • The remaining categories (Screen Reader Tech, SMS, Database, Domain, Maps) are shared/fleet-wide costs that stay the same whether CSAH runs 1 kiosk or 3 — Screen Reader Tech (JAWS) is a license across the fleet and also has additional implementation fees, not a per-unit cost.
  • Hosting assumes Netlify Pro ($20/mo = $240/yr), not the free tier
    — Netlify's free tier does not support deploying from a private repository owned by a GitHub Organization, which is what CSAH's app repo will be. This isn't a later-stage upgrade; it's required from day one. Hosting cost should still scale based on a larger threshold than 3 kiosks — re-eval once traffic is known and more kiosks are added.
  • Assumes a subdomain of homelessauthority.org is used instead of purchasing a new domain name.

Selected scenario: Metro + build Screen Reader. Metro handles kiosk hardware, lockdown, and connectivity as a bundle, and the screen reader is built into the app rather than licensed — avoiding the JAWS $3,600 + fees line entirely. Lands at $4,190/yr for 3 kiosks, roughly $1,450 more than fully unbundled vendors and about $3,600 less than the JAWS path.
"All vendors independent" Kiosk Software License ($425/kiosk/yr) = KioWare Enterprise license ($195/device/yr) + KioCloud remote management ($230/device/yr) — see Kiosk Software comparison doc. SMS, Database, Hosting, Domain, and Map/Tiles are shared platform costs, so they're identical across all three scenarios. Screen Reader Tech (JAWS) is also shared, not per-kiosk — it's a single license across the fleet fpr every 3 year cadence, so it's only counted once in the 3-kiosk total, not multiplied. Only Kiosk Software License (HW Monitoring) and Cellular scale directly with kiosk count. Domain assumes a subdomain of homelessauthority.org is used instead of purchasing a new domain (see Hosting doc). Kiosk Software License (HW Monitoring) Per Kiosk $700 flat Updated per-kiosk figure: $700/unit/yr. Scales directly with kiosk count — 3 kiosks = $2,100/yr. Costs include: heartbeat, health alerts, remote reboot, automatic OS and software updates, remote troubleshooting of hardware.
Screen Reader Tech Shared $0 flat $0 recurring under the selected scenario — the screen reader is built into the app by ARC rather than licensed, using the browser's built-in Web Speech API. There is no per-device or per-year license to renew, and no vendor to depend on for accessibility.

The alternative is JAWS — is the $3,600/yr line in the third scenario column. That's a fleet-wide license, not per-kiosk, and carries additional implementation fees on top that were quoted at over $6K. License cost ever 3 years would be an additional $3,600. Flagging: the $3,600 figure is a planning estimate carried over from earlier budgeting — it is not tied to a Freedom Scientific quote and the implementation fees are unquantified. Get a written quote before treating that scenario's total as real.

The real cost here is build effort, not recurring spend. Choosing to build shifts the expense into the development Phase — and screen-reader behavior on real hardware can't be verified by automated tooling, so manual accessibility testing on the kiosks is required either way. Paid for as part of contract consulting fees.
Cellular Connectivity Per Kiosk $450 flat Updated per-kiosk figure: $450/unit/yr. Managed IoT SIM (multi-carrier, e.g. Hologram-style) — the recommended lean approach per the Kiosk Connectivity comparison doc. Independent of kiosk hardware vendor. Scales directly with kiosk count — 3 kiosks = $1,350/yr. Includes remote troubleshooting of modem.
SMS (Twilio) Shared $120 – $240 Estimated at 400 texts/month combined across the kiosk fleet (~13/day total) — Worked estimate against Twilio's public rate card, assuming resource-info texts average 2 SMS segments each (shelter name/address/hours easily exceeds the 160-character single-segment limit): 800 segments × ~$0.0079 (~$6.32) + A2P 10DLC per-segment carrier surcharge (~$2.40) + phone number rental (~$1.15) + A2P 10DLC monthly campaign fee (~$1.50–$10, varies by tier) ≈ $132–$240/yr. Treated as a shared platform cost — one Twilio account serves all kiosks, not a per-unit charge. This is a worked estimate from public pricing, not a live Twilio quote — verify current rates before treating as final. Twilio confirmed as provider (2026-08-04); not yet contracted/registered (A2P 10DLC campaign registration still needs to be filed).
Database (Supabase) Shared $300 flat Budgeting Supabase Pro flat rather than starting on the free tier. Free tier has no backups — not an acceptable risk, even though row/bandwidth limits would likely allow staying on Free at launch scale otherwise. One project serves the whole system regardless of kiosk count.
Hosting Shared $240 flat Netlify Pro required, not free tier — Netlify's free tier does not support deploying from a private repository owned by a GitHub Organization, which CSAH's app repo will be. $240/yr ($20/mo) also happens to include priority support, 1TB bandwidth, and 400 build minutes, but those aren't why it's needed. One deployment serves all kiosks and the staff app. Flagging: this Netlify policy hasn't been independently re-verified against their current docs — confirm before treating as final.
Domain Name Shared $12 – $20 Standard annual domain registration for a .org. Heavily consider subdomain on https://www.homelessauthority.org/ to save costs and keep consistency.
Map / Tiles Shared $0 – $120 Covers embedding a map directly in the app for wayfinding/directions instead of linking out. Easy to assume this is free the way consumer Google Maps is — it's technically a metered developer API, not a truly free product. That said, per ADR-008, cost is effectively a non-factor at CSAH's projected volume, especially combined with the lazy-caching approach for directions (fetch once, reuse for 30 days) — the small ceiling here is a buffer, not an expected charge. Self-hosted OpenStreetMap (OSM) tiles remain on the table as a $0 path regardless of which vendor is chosen. Vendor/approach not finalized — see ADR-008.
Possible additional costs — not included in the total above
