Connectivity: WiFi vs. Ethernet vs. Cellular

Preferred

Wired Ethernet

Highest stability, lowest latency, no wireless interference. Best choice for kiosks handling sensitive data and expected to run 24/7. Requires trenching conduit to run cable underground plus a certified network installer at each site.

Extra installation cost: $1,000–$2,500 per unit. Pursue wherever conduit to a nearby building is feasible.

Workable in lobbies

WiFi

Cost-effective where the host facility's existing network reaches the kiosk location — no trenching required. Can be affected by signal interference and congestion in crowded environments, which shelters and drop-in spaces often are. If WiFi is the only option, require WiFi 6 (802.11ax) support from the hardware vendor for better performance.

No extra infrastructure cost if the building's network reaches the placement location.

Outdoor fallback

Cellular (4G/5G)

The realistic option for any truly outdoor standalone placement with no nearby building infrastructure. All three vendors (Advanced Kiosks, MetroClick, Olea) support wired Ethernet, WiFi, and 4G/5G cellular. Plan for cellular as primary connectivity in those placements, with WiFi as secondary if available.

Ongoing cost: $30–$80/month per unit ($360–$960/year). Budget this as an operational line, not hardware.

CSAH site visit recommendation For each of your 3–4 locations, assess connectivity options during site visits before ordering hardware. If you can run conduit to a nearby building, wired Ethernet is the right call. If not, plan for cellular as primary with WiFi as secondary. Do not assume placement decisions until site visits are complete — connectivity plan should inform hardware spec, not the other way around.
