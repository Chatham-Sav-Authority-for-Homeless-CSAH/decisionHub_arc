Data Privacy is a non-negotiable, not a nice-to-have The requirements introduce a detailed data governance section informed by the LinkNYC case study — in which public kiosks collected browsing history, retained camera footage, and enabled hyper-targeted advertising on homeless users. CSAH must contractually prevent these failure modes. Vendors whose software stacks transmit session or behavioral data to their own servers are a compliance risk regardless of hardware quality or price.
No Section 508 requirement CSAH is not federally funded, so federal accessibility law (Section 508) does not apply. WCAG 2.1 AA is the target standard. ADA physical compliance (48" max height, 30"×48" clear floor space) is required for all units.

Connectivity: WiFi vs. Ethernet vs. Cellular

Preferred

Wired Ethernet

Highest stability, lowest latency, no wireless interference. Best choice for kiosks handling sensitive data and expected to run 24/7. Requires trenching conduit to run cable underground plus a certified network installer at each site.

Extra installation cost: $1,000–$2,500 per unit. Pursue wherever conduit to a nearby building is feasible.

Workable in lobbies

WiFi

Cost-effective where the host facility's existing network reaches the kiosk location. Can be affected by signal interference and congestion in crowded environments. If WiFi is the only option, require WiFi 6 (802.11ax) support from the hardware vendor.

No extra infrastructure cost if the building's network reaches the placement location.

Outdoor fallback

Cellular (4G/5G)

The realistic option for truly outdoor standalone placements. All three evaluated vendors support Ethernet, WiFi, and cellular. MetroClick confirmed AT&T, Verizon, and T-Mobile support — cellular stability depends on the installation location.

Ongoing cost: $30–$80/month per unit ($360–$960/year). Budget as an operational line, not hardware.

CSAH site visit recommendation For each of your 3–4 locations, assess connectivity options during site visits before ordering hardware. If you can run conduit to a nearby building, wired Ethernet is the right call. If not, plan for cellular as primary with WiFi as secondary. Do not finalize hardware specs until site visits are complete — connectivity plan should inform the hardware order, not the other way around. MetroClick recommends positioning the kiosk directly over a ground outlet to keep all electrical elements locked behind the unit.
