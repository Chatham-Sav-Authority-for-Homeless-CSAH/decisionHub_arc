Netlify Pricing — Why Pro, Not Free

Netlify was picked as the cost winner, but the original plan to start on the free tier doesn't hold up: Netlify's free tier does not support deploying from a private repository owned by a GitHub Organization, and CSAH's app repo will be exactly that (CSAH GitHub Org, private repo). That's not a usage-driven upgrade decision — it's a hard blocker from day one, regardless of how little bandwidth or how few builds CSAH actually uses. The usage numbers below are still worth keeping — they show Pro's headroom is nowhere close to being tested, so cost won't grow with usage even though the base $19/mo is now unavoidable.

Bandwidth — 1TB/mo on Pro

We'd have to be serving enormous assets to approach that. A typical React PWA with a cached service worker is a 1–5MB initial load, then minimal traffic on repeat visits.

Map tile traffic

Google Maps tiles are served directly from Google's CDN — they don't pass through Netlify at all. Tile bandwidth is billed by Google Maps Platform, not Netlify. Not a Netlify concern.

What actually hits Netlify

  • The React PWA bundle (initial load + service worker cache)
  • Any API calls routed through Netlify Functions (Twilio, etc.)
  • Static assets — icons, fonts, manifest

With lazy caching, repeat visits serve almost entirely from the service worker cache. First load per user per device is the only real Netlify bandwidth hit — and that's still just the app bundle, not map tiles.

Build minutes — 400/mo on Pro

Each GitHub push triggers a build. At normal development velocity (say, 1–5 deploys a day) we'll burn maybe 150/mo. Comfortable headroom even during heavy sprints.

Support — priority email included on Pro

Free tier is community-only; Pro includes priority email support. Since Pro is required regardless, CSAH gets this by default rather than as something to weigh separately.

SLA — still none below Enterprise

Netlify's measured uptime is excellent (>99.9% per independent monitoring), but there's no contractual guarantee or service credits on Pro — only on Enterprise. Being on Pro doesn't change this.

What $19/mo Pro gets CSAH, on top of solving the repo-access blocker

  • Priority email support
  • 400 build minutes (vs. 300 on free)
  • 1TB bandwidth (vs. 100GB on free)
  • Password protection on deploy previews
  • Larger serverless function limits
Recommendation: Budget $19/mo for Netlify Pro from launch — it's not optional given the private GitHub Org repo, so there's no "start on free and revisit" path here. The usage headroom (1TB bandwidth, 400 build minutes) is generous relative to CSAH's actual traffic, so cost won't grow as the project scales; this is a flat, predictable line item. Worth confirming whether Cloudflare Pages has the same restriction — if it doesn't, it's worth a second look as a genuinely free alternative.
