Each Piece, Explained

Code Repository :: GitHub Decided

Think of this as the master filing cabinet for the app's code. Every change ARC makes gets saved here first — it's the single source of truth, and it's what Netlify pulls from to publish updates.

Hosting :: Netlify Decided

The hosting service — it takes the code from GitHub and makes it live on the internet. Runs on Netlify's Pro plan ($20/mo, $240/yr) rather than the free tier — Netlify's free tier reportedly doesn't support deploying from a private repo owned by a GitHub Organization, which CSAH's will be. See the Hosting comparison doc for the full reasoning.

DNS Provider (Domain) :: SiteGround Open Item

Domain Name Servers (DNS) are the servers that translate domain names into IP addresses which are the web address people type to reach the app (e.g. homelessauthority.org). Two options are still open: a subdomain of homelessauthority.org (CSAH already owns this domain, so a subdomain would likely be free or low-cost to set up) or a new, separate domain name. (typically $10–20/yr to register, plus renewal each year). See the Hosting comparison doc for the tradeoffs. Recommended approach is compassApp.homelessauthority.org & kiosk.homelessauthority.org

Frontend Decided

The framework used to build Kiosk Compass and the CSAH App is React — a widely used, well-supported toolkit for building fast, interactive web apps. Both surfaces are built with it, which is part of why they can share code and components.

MDM (Kiosk Lockdown Software) :: MetroClick Decided

MDM stands for Mobile Device Management — software that locks a touchscreen down to a single app or website, blocks access to the browser's address bar, settings, and other apps, and lets an administrator remotely monitor, update, and reboot the device. It's what turns an off-the-shelf touchscreen into a public kiosk instead of an open computer. MDM is bundled with the kiosk hardware, not a separate purchase. See the Kiosk Software comparison doc for how this was evaluated against other vendors.

Cellular Connectivity :: MetroClick Decided

The kiosks are outdoor, standalone units — they need their own internet connection to reach Netlify and Supabase, so each one needs a cellular data plan (like a SIM card in a phone). MetroClick provides this as part of its kiosk hardware/software bundle. This is separate from the CSAH App, which runs on staff devices that already have their own connectivity. See the Kiosk Connectivity doc for detail.

Database:: Supabase Decided

The shared database behind both Kiosk Compass and the CSAH App. One source of data means a shelter's hours only ever need to be updated in one place, and both surfaces stay in sync automatically. It also handles staff login for the CSAH App — see Auth below.

Auth (Login) :: Supabase Decided

Staff login for the CSAH App is handled by Supabase Auth — it's built into the same Supabase system that runs the database, not a separate service. Kiosk Compass doesn't need this at all; it's public, no login required.

SMS Message Alerts:: Twilio Decided

When someone at a kiosk requests help, an SMS message goes out to the CSAH outreach team as a nudge — the request itself is saved first, so it's never lost even if the text doesn't arrive. Twilio is the texting provider.

Push Notifications Decided

Inside the CSAH App, staff get real-time push notifications for crisis coordination and case updates — the same way a texting app pings you, but built into the CSAH App itself. Delivered via the Web Push API, implemented directly rather than through a managed vendor — a Supabase Edge Function sends the push, with subscriptions stored in Supabase's database. This requires a service worker (a small background script the browser runs to receive pushes even when the app isn't open).

Maps Provider :: Google Maps Decided

Powers the maps embedded in the app — showing shelter, meal, and service locations, and giving directions. This is a separate service the app pulls map data from. See the Annual Costs doc for the cost tradeoffs.
