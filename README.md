# Compass Project — ARC Working Repo

**Client:** Chatham Savannah Authority for the Homeless (CSAH)
**Team:** Alan Robinson & Allyson Short (ARC)

---

## What this is

This is the working repository for the Compass Project — ARC's engagement to design and build the CSAH kiosk network and Compass Companion App.

If you're looking for decision documents and research, you don't need to be here. Everything is published to a live website you can open in any browser:

**→ [csahcompassapp.netlify.app](https://csahcompassapp.netlify.app)**

---

## What's in this repo

### `docs/`
The decision hub. Every research document, vendor comparison, and architecture recommendation lives here as a web page. Netlify automatically publishes this folder to the live site whenever Allyson pushes an update — so the URL above is always current.

### `CLAUDE.md`
Project context for Claude Code, the AI development tool Allyson uses. It keeps Claude informed about the project — the client, the scope, how we work, key decisions, and open questions. You don't need to read or edit this, but don't delete it.

### `.gitignore`
A list of local files that should never be uploaded to GitHub (credentials, personal settings, etc.). Ignore this.
